# ============================================================================
# FILE:       backend-test/requirements.txt
# PURPOSE:    Every Python package the TaskFlow backend needs at RUNTIME.
#             Vercel installs this file during the build step.
# HOW IT WORKS: One package per line as `name==exact.version` so every
#             machine and every deployment gets an identical environment.
#             Development-only packages (pytest & friends) live in
#             requirements-dev.txt so the deployed bundle stays small and the
#             cold start stays fast.
# USED BY / DEPENDS ON: Vercel build step, `pip install -r requirements.txt`.
# KEY CONCEPTS: dependency pinning, runtime vs development dependencies.
# ============================================================================

# python-multipart lets FastAPI parse multipart/form-data (CSV/JSON upload)
